## 🔧 FIX: Install RDLC Report Designer

### Step 1: Close Visual Studio ❗

(Important — don’t skip)

---

### Step 2: Install RDLC Extension

Open this **inside Visual Studio**:

**Extensions → Manage Extensions**

Search for:

```
Microsoft RDLC Report Designer
```

Publisher: **Microsoft**

Click **Install**

✔ Accept → Close VS → Let it install → Reopen VS

---

### Step 3: Verify It Worked

Now try:

**Right-click Project → Add → New Item**

You should see one of these:

* **Report**
* **RDLC Report**
* **Report Definition File**

If yes → you’re good 🎉

Project -> Right Click -> Add -> New Item... -> Report
